# 关于

这是我的个人技术知识库，用来整理学习和工作中遇到的知识点，记录问题与处理过程，也留下值得回顾的理解和心得。

内容主要涉及广告系统、GPU 与 AI 基础设施、大模型推理和 AI Agent，也会逐步补充操作系统、分布式系统和常用工具的笔记。

## 当前阶段

目前按 AI Agent、AI Infra、分布式系统、操作系统、K8s、Redis 和 Kafka 整理学习笔记。内容会持续修订；正文保留了资料来源、历史版本和未实测说明。

## 如何阅读

- 从[知识库](/knowledge/)按领域和分册查阅。
- 从[技术专题](/topics/)按顺序学习。
