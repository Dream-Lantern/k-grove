# 第十四章 内存分配、碎片与分区算法

> 阅读标签：通用内存分配教学模型。

内存分配需要从空闲空间中找到满足请求的区域。能否分配成功，既取决于剩余总量，也取决于连续性要求、空闲块的组织方式与合并策略。本章用 first/best/worst fit 比较选择规则，再区分应用分配器与内核的管理对象。

## 1. 内部碎片与外部碎片

内部碎片是已分配单元中未被有效使用的部分，例如按固定粒度分配后留下的尾部空间；外部碎片是空闲空间分散，虽然总量足够却没有满足连续要求的大块。

教学例子：空闲块分别为 6、4、8 单位，总量 18，但若请求必须连续 10 单位就无法满足。分页可以降低普通虚拟连续映射对物理连续的需求，却不消除所有分配和大页碎片问题。

## 2. First、Best 与 Worst fit 的选择规则 {#_2-first-fit-不天然是-o-1}

First fit 选择扫描中第一个足够大的块；链表实现最坏可能扫描多个空闲块，因此通常不能无条件写成 O(1)。空闲链表排序、分级索引、位图等数据结构会改变成本。

Best fit 寻找足够且最接近请求的块，可能产生许多小余块；worst fit 选择最大的空闲块，也不保证未来分配更均匀或更少失败。策略需要结合分配分布与实现比较。[OSTEP Free-Space Management](https://pages.cs.wisc.edu/~remzi/OSTEP/vm-freespace.pdf)

## 3. 一个可以手算的例子

按地址顺序的空闲块为 12、5、9，请求 4：first fit 从 12 中分配，best fit 选 5，worst fit 选 12。之后各有不同余块，但不能只看本次剩余最大的块就断言长期优劣。

可以继续请求 8、6，允许分割空闲块，再加入释放与相邻块合并，观察结果如何变化。这里均使用合成单位，未在当前主机上分配或释放内存。

## 4. 应用分配器与内核物理分配不同

malloc 管理进程中的适用虚拟空间与对象，不一定每次都向内核申请一个新页。释放对象也不保证立即将相应物理页归还系统；分配器可能保留空间复用。

内核还可能采用页级分配与更小对象缓存等机制。把“进程申请 20 字节”“内核分配一个页框”“虚拟空间映射增加”混成一件事，就无法解释 RSS、堆大小和碎片的差异。

## 5. 固定分区与可变分区 {#_5-固定分区不要求永远等分}

固定分区事先规定各区域的边界与大小，可以等大，也可以按需求设置不同大小；等分为 n 区是其中一种简化模型。可变分区则按需求安排边界，承担查找、分割、合并与碎片管理成本。

分页、分段、分配器和压缩分别在不同层次缓解问题。讨论优化前，应先明确管理对象与连续性要求，不能将某个教学算法直接用于所有现代堆或内核。
