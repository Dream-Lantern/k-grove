## 示例的副作用分类

CUDA/Python 代码可能初始化设备或执行工作；profiling 会启动应用并写报告；Docker run 会启动容器。MIG 变更语法另列为高风险占位参考，不生成可直接执行的批量销毁命令。

本次仅生成文档和图片，没有执行正文中的任何示例。静态语法、链接和图源检查不能代替 CUDA 编译、真实硬件测试、压力测试或故障注入。

## 仍需目标环境验证

- GPU 与所选 Toolkit/驱动、镜像、框架的兼容组合。
- MIG profile、placement、P2P、枚举与通信库支持。
- MPS 接口、故障影响和资源限制粒度。
- HAMi 对新 API、异步分配、Graph 等路径的实际覆盖。
- 引擎在指定模型、量化、上下文和并发下的质量与容量。

这些问题需要通过运行环境验收确认，不能仅靠文字润色作出保证。

## 本轮版本对照与来源边界

外部审阅以 CUDA 12.4、NVML R535、SGLang v0.4.9 等定位旧稿问题；本册原有机制参考为 CUDA 12.8.1，不能无说明地混成同一实测环境。新增 GI/CI 类型链特意引用 R535，MPS 终止接口标 Release 615，HAMi 协议标 v2.10.0；这些均不代表原 2024/2025 环境已支持相应新能力。
